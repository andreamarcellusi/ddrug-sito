# Sito DDRUG

Sito del gruppo di ricerca Drug Delivery & Regulatory Affairs (DiSFarm, Università degli Studi di Milano).

- `content/`: i dati del sito (persone, corsi). Si aggiornano a partire dalla cartella Drive "Sito DDRUG".
- `templates/`: la grafica.
- `assets/`: logo e immagini.
- `docs/`: il sito generato, servito da GitHub Pages. Non si modifica a mano.

Per rigenerare: `python3 build.py`
